# 🛰 VPN Master

Личный Telegram-бот для управления VPN-инфраструктурой на **Remnawave**: установка панели, нод, ботов Bedolaga, модификаций, настройка безопасности и обновления — всё кнопками, по SSH.

- **Стек:** Python 3.12, aiogram 3, PostgreSQL 17, asyncssh, Docker Compose
- **В `.env` только** `BOT_TOKEN` и `OWNER_ID`. Серверы, ключи, пароли, панели и настройки лежат в PostgreSQL.
- **Секреты** (пароли, приватные ключи, токены) шифруются Fernet. Мастер-ключ: `data/master.key`.
- Бот отвечает **только владельцу** (`OWNER_ID`).

## Установка

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/tneange1/vpn-master/main/install.sh)
```

Скрипт поставит Docker, склонирует репозиторий в `/opt/vpn-master`, спросит токен бота и твой Telegram ID и запустит `bot` + `db`.

Вручную:

```bash
git clone https://github.com/tneange1/vpn-master /opt/vpn-master && cd /opt/vpn-master
cp .env.example .env && nano .env
docker compose up -d --build
```

Обновление: `cd /opt/vpn-master && git pull && docker compose up -d --build`

## Разделы

### 📦 Установка проектов
| Проект | Что делает |
|---|---|
| **Remnawave** | `/opt/remnawave`: скачивает compose и `.env` из [remnawave/backend](https://github.com/remnawave/backend), генерирует секреты, поднимает панель. Создаёт супер-админа и API-токен через API, ставит страницу подписки и Caddy с автоматическим SSL. |
| **Bedolaga Bot** | `/opt/remnawave-bedolaga-telegram-bot`: клонирует репозиторий и заполняет `.env` (webhook, Web API, Remnawave API, Postgres). Если бот на одном сервере с панелью, берёт `docker-compose.local.yml`. Добавляет сайт для вебхуков в Caddy. |
| **Bedolaga Cabinet** | Включает `CABINET_*` в боте, поднимает `ghcr.io/bedolaga-dev/bedolaga-cabinet` в сети бота, добавляет сайт в Caddy (`/api/*` уходит в бота). |
| **Подключить панель** | Добавляет уже установленную панель: домен и API-токен, SSH по желанию. |

На первом шаге каждой установки выбираешь сервер или добавляешь новый. Способ входа на выбор:
🔑 сгенерировать ключ и поставить его (пароль нужен один раз), 🔒 пароль, 🗝 ключ из хранилища, 📋 вставить свой ключ.

### 🛠 Управление
- **Панели**
  - ➕ **Нода**: создаёт профиль (VLESS TCP Reality self-steal / Hysteria2 / оба), ноду, хосты и инбаунды во внутреннем скваде через API. На сервере ставит self-steal Caddy (заглушка на `127.0.0.1:9443` с настоящим сертификатом) и `remnawave/node`.
  - Профили (список, скачать JSON, создать), сквады (список, создать), рестарт и удаление нод.
- **Модификации**
  - 🔗 [Link Extractor](https://github.com/tneange1/link-extractor): на каждую панель, со своим ботом. Если Caddy управляется ботом, маршруты прописываются сами.
  - 💾 [Backup-Restore](https://github.com/distillium/remnawave-backup-restore): на каждую панель, со своим ботом. Установщик интерактивный, поэтому запускается во встроенном терминале.
  - 🌐 [WARP-native](https://github.com/distillium/warp-native): на каждую ноду. Установка в терминале, `warp-out` добавляется в профиль ноды через API (AI/стриминг или весь трафик).
- **Безопасность**
  - UFW: правила по ролям сервера, на ноде порт 2222 открыт только для IP панели.
  - Вход по паролю SSH вкл/выкл. Выключить можно только после проверки, что вход по ключу работает.
  - Защита панели секретной ссылкой: Caddy пускает только с cookie, ссылка `https://панель/?vmkey=…`.
- **Обновления**: панель, подписка, Caddy, каждая нода (или все по очереди), self-steal, Bedolaga, кабинет, Link Extractor. Всё по отдельности.

### 🔐 Доступы и серверы
Серверы: проверка, 💻 интерактивный терминал, ⌨️ команда, пароль (показывается под спойлером и удаляется), способ входа, сброс host key. SSH-ключи: генерация ed25519, импорт, скачивание. Логины и API-токены панелей, токены ботов.

### 💾 Бэкап бота
`pg_dump` всей БД плюс `master.key` в одном `tar.gz`, отправляется владельцу в Telegram. Автобэкап раз в 6/12/24/72 ч. Восстановление: прислать архив боту.
⚠️ В архиве лежит ключ расшифровки, храни его как пароли.

## Как это устроено
- Каждое действие на сервере — bash-скрипт, который уходит по SSH через stdin. Лог обновляется в сообщении в реальном времени, полный лог приходит файлом.
- Host key сервера запоминается при первом подключении (TOFU), дальше сверяется.
- Caddy на сервере панели живёт в `/opt/remnawave/caddy`, сайты лежат в `sites/*.caddy`. Чужой работающий Caddy бот **не трогает**: он выводит блок конфига, чтобы ты добавил его вручную.

## Что проверить на своей версии
- **Hysteria2**: в Xray-core протокол `hysteria` появился недавно, и схема ещё меняется. Если панель не принимает профиль, поправь инбаунд в «Профили → 📄 JSON».
- Переменные `.env` Bedolaga (`REMNAWAVE_AUTH_TYPE`, `REMNAWAVE_SECRET_KEY`) взяты из документации. Сверь их с `.env.example` своей версии бота.
- Нода и панель на одном сервере не поддерживаются: оба используют 443.

## Структура
```
bot/
  __main__.py      запуск, доступ только владельцу
  config.py        BOT_TOKEN, OWNER_ID
  db.py            модели PostgreSQL
  crypto.py        шифрование секретов
  ssh.py           asyncssh: подключение, запуск, ключи
  runner.py        скрипт → живой лог в Telegram
  terminal.py      интерактивный терминал
  rw_api.py        клиент Remnawave API
  xray.py          профили Reality / Hysteria2 / WARP
  scripts.py       bash-сценарии установок, обновлений, безопасности
  forms.py         пошаговые формы
  backup.py        бэкап/восстановление бота
  handlers/        меню и разделы
```
